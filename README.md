# jers-final-year-project

## WANDER
**Academic Title:** Gamified Mindfulness for Stress and Anxiety Management Using Real-Time Eye Tracking and Blink Detection  
**Commercial Title:** WANDER

## Overview
WANDER is a mobile mindfulness experience that explores how real-time eye tracking and blink detection can be used as interactive tools for stress and anxiety management.

Built in Unity for Android using C#, the project places the player in a calm, hand-drawn forest world where focus-based encounters encourage slower breathing, steady attention, and present-moment awareness.

Instead of fast-paced goals or text-heavy interaction, WANDER uses gentle visual feedback and neuroinclusive design principles to reduce cognitive load and better support users with ADHD, dyslexia, or general overstimulation.

The project combines game design, mobile development, and computer vision to investigate how playful digital experiences can promote emotional regulation and mindful engagement.

## Technology Stack
- Unity
- Android
- C#
- Mobile camera input
- Eye tracking
- Blink detection
